💰 FinTrack — Personal Finance Intelligence Platform

📌 About the Project

FinTrack is a personal finance platform designed to help users manage their income, expenses, and financial activities in one place.

✨ Features

Track income and expenses

Manage personal financial records

View financial summaries and insights

Secure user authentication

🛠️ Tech Stack

Frontend: React.js

Backend: Node.js, Express.js

Database: PostgreSQL

ORM: Prisma

🚀 Future Improvements

Interactive financial dashboards

Budget planning

Spending analytics

Monthly reports
